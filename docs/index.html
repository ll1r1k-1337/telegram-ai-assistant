Telegram AI Assistant

AI-подсказки по ответам прямо в web.telegram.org — выберите провайдера, откройте чат, получите варианты ответа за секунды.

Chrome Extension Manifest V3 TypeScript MIT License
⬇️ Установить ⭐ GitHub

Подсказки генерируются за 1–3 секунды и адаптируются под контекст чата

Возможности

🤖

Умные подсказки

2–3 варианта ответа, адаптированных под тон и контекст переписки — краткий, развёрнутый, нейтральный.

⚡

Мгновенная вставка

Клик по подсказке — текст сразу появляется в поле ввода Telegram. Alt+1/2/3 для клавиатуры.

🎨

Адаптивная тема

Панель подсказок автоматически подстраивается под светлую и тёмную тему Telegram.

🌍

Мультиязычность

Автоопределение языка чата — подсказки генерируются на том же языке, что и переписка.

🔒

Приватность

Минимальные permissions. Данные не покидают устройство кроме запроса к AI. Опциональная анонимизация имён.

🛠

Любой провайдер

OpenAI, Anthropic, Ollama (локально), или любой OpenAI-совместимый API. Ваш ключ — ваши правила.

Как это работает

1

Content Script читает чат

Расширение парсит последние сообщения из DOM web.telegram.org через MutationObserver — без API Telegram.

2

Контекст → AI провайдер

Сообщения, тип чата и язык отправляются в выбранный AI-провайдер через Background Service Worker.

3

Подсказки появляются над полем ввода

2–3 варианта ответа отображаются как кликабельные чипсы. Выбрали → текст в поле ввода.

Установка

Клонируйте репозиторий и соберите расширение за 30 секунд

# Клонирование и сборка
git clone https://github.com/<owner>/telegram-ai-assistant.git
cd telegram-ai-assistant
npm install
npm run build

# Затем: chrome://extensions → Загрузить распакованное → dist/
