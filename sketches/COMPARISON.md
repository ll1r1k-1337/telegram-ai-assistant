# E6-001: Дизайн — Mockup UI подсказок

## Три варианта UI подсказок ответов

Каждый вариант — полноценный интерактивный HTML-файл, имитирующий Telegram Web (dark theme) с AI-подсказками. Все поддерживают:
- Горячие клавиши Alt+1/2/3 для вставки, Alt+/ для toggle, Esc для скрытия
- Анимации загрузки (loading state)
- Клик по подсказке → вставка в поле ввода
- Light/dark theme (media query)

## Сравнение

| Параметр | 001: Inline Chips | 002: Floating Panel | 003: Input Drawer |
|---|---|---|---|
| Позиция | Между сообщениями и input | Floating overlay справа | Выдвижная панель из input |
| Перекрытие чата | Нет | Да, частичное | Нет (сдвигает) |
| Плотность информации | Низкая | Высокая | Средняя |
| Длинные подсказки | Обрезаются | Полные | Полные |
| Дополнительные действия | Нет | Regenerate | Ещё/Длиннее/Формальнее |
| Тон/метаданные | Нет | Tone tag | Tone pill + word count |
| Триггер | Кнопка 💡 рядом с send | FAB-кнопка | Кнопка 💡 + auto badge |
| Сложность DOM-инъекции | Простая | Средняя | Сложная |
| Нативность ощущения | ⭐⭐⭐ | ⭐⭐ | ⭐⭐⭐ |
| Пригодность для auto-trigger | ⭐⭐ | ⭐ | ⭐⭐⭐ |

## Рекомендация

**003: Input Drawer** — лучший баланс:
- Не перекрывает чат (в отличие от floating panel)
- Показывает полный текст подсказок (в отличие от chips)
- Имеет кнопки уточнения (Длиннее, Формальнее) — ключевая фича для AI-ассистента
- Badge-уведомление на кнопке для auto-trigger — не навязчиво, но заметно
- Чувствуется как расширение input area, а не отдельный UI

**Chips** (001) — хороший fallback для MVP, если нужна максимальная простота реализации.
**Floating panel** (002) — перебор для расширения; ощущается как отдельное приложение.

## Как открыть

```
start sketches\001-inline-chips\index.html
start sketches\002-floating-panel\index.html
start sketches\003-input-drawer\index.html
```

Все файлы самодостаточные, открываются в любом браузере.
